# Struttura del Progetto 📂

```text
/src
  /app                  # Pagine principali, App.tsx core e logica di routing/fase
  /components
    /ui                 # Bottoni, testi, componenti puramente visuali
    /cinematic          # Video players, intro, Three.js 360 canvas, telecamere
    /batcomputer        # UI specifica del computer di batman
    /showreel           # Elementi marketing (Pricing, Checkout, Thanks)
    /mission            # Logica indizi, logica minigiochi
    /hud                # Timer, progress bar
    /transitions        # Transizioni, glitch, overlay d'impatto
    /joker              # Hint system, carte del joker, overlay verdi
  /hooks                # Custom hooks (audio, mobile, timer)
  /lib                  # Configurazioni globali 
  /utils                # Funzioni di utilità generica
  /data                 # Costanti e copy testuale
  /styles               # Design System (index.css)
  /assets               # Immagini, texture, video
```

# Gameflow & UX 🎮

Il flusso è rigidamente guidato, pensato per massimizzare la tensione.

1. **Intro:** Video glitch, stabilisce il contesto narrativo (Joker ha infiltrato la rete).
2. **Investigation (3 Fasi):**
   - *Batcomputer:* 0/5 Indizi.
   - *Armeria:* 2/5 Indizi.
   - *Batmobile:* 3/5 Indizi.
3. **Breather:** Tensione scaricata, sistema ripristinato.
4. **Reveal:** Entrata epica della statua.
5. **Showreel & Checkout:** Fase finale marketing, acquisto.

**Scelte UX chiave:**
- Assenza totale di scrollbar durante l'investigazione.
- Mouse look (drag) costantemente attivo.
- Feedback visivo (verde) quando il Joker interviene.

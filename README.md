# 🦇 Batman Statue Experience

Benvenuti nel repository ufficiale della landing page interattiva dedicata all'87° anniversario di Batman.

## 📖 Documentazione Completa
Per una spiegazione dettagliata delle logiche di funzionamento, degli script e delle tecnologie utilizzate, consulta il file:
👉 **[DOCUMENTATION.md](./DOCUMENTATION.md)**

## 🚀 Avvio Rapido

**Prerequisiti:** Node.js (v18+)

1. **Installa le dipendenze:**
   ```bash
   npm install
   ```

2. **Configura le API (opzionale):**
   Imposta la tua `GEMINI_API_KEY` nel file `.env` se utilizzi le funzioni AI.

3. **Avvia il server di sviluppo:**
   ```bash
   npm run dev
   ```

Il progetto sarà disponibile su [http://localhost:3000](http://localhost:3000).
